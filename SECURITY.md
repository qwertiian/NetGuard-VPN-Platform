# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

Please **DO NOT** report security vulnerabilities via public GitHub issues.

Instead, please report them by emailing `security@netguard.example.com`.
We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.

## Responsible Disclosure

We ask that you follow responsible disclosure guidelines and give us time to investigate and patch vulnerabilities before publishing them.

## Security Update Policy

Security updates will be released as patch versions for the current major/minor release.

## Scope

- Vulnerabilities in NetGuard VPN core logic.
- Vulnerabilities in our direct dependencies that affect the application.
Not covered:
- Vulnerabilities in user's OS or unsupported environments.
